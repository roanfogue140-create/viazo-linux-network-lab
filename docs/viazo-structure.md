# VIAZO Server Structure

## Runtime directory

/opt/viazo/

├── app/
├── backups/
├── configs/
├── logs/
├── reports/
└── scripts/

## Description

app/      : application VIAZO
backups/  : sauvegardes
configs/  : fichiers de configuration
logs/     : journaux système et application
reports/  : rapports
scripts/  : scripts Bash d'administration
